# Execution logs

Slurm job logs for this recipe land here (`hyenadna-infer-<jobid>.out` /
`.err`), written by `slurm/infer_hyenadna_makerspace.sbatch`'s
`#SBATCH --output=logs/...` / `--error=logs/...` directives.

See `../README.md`'s [Execution evidence](../README.md#execution-evidence)
section. `local-cpu-dryrun/` is a pre-flight CPU validation of the recipe
itself, run before the actual ICE/AI Makerspace GPU job.
